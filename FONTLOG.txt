FONTLOG for the Pusto Pin font
==============================

This file provides detailed information on the Pusto Pin font family.
This information should be distributed along with the Pusto Pin fonts
and any derivative works.


Basic Font Information
----------------------

Pusto Pin is a rounded unicase stroke typeface by Pustota, supporting
Latin and Cyrillic. It was drawn for the Pusto pins. It is developed in
Glyphs and distributed here in OTF and web (WOFF, WOFF2) formats.
